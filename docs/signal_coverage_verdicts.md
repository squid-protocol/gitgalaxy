## Sibling gaps (not fixed here)

* Auth Middleware: the python rule matches `def check_password(` / `def check_password_hash(` definition sites (only `authenticate(` is def-guarded); other languages' auth rules (go, java, php, ruby, csharp) were not probed in slice 8; `jwt.decode` and `passport.use` are left out (decode may be unverified, `use` only registers a strategy).

* Global Environment Mutation: any other `os.environ[...] =` / `process.env.X =` write is ordinary configuration (tests set them everywhere) and stays unmatched; `Object.assign(Foo.prototype, ...)` mixins likewise. `globals()[...] =`, `setattr(builtins, ...)`, `builtins.open =` and `sys.path.insert` are unread and need a contract decision on what counts as global state.
* Embedded Credentials still unread: unquoted `.env` / YAML values (`DB_PASSWORD=...`), connection-string passwords (`scheme://user:pw@host`), camelCase names (`dbPassword`), `ssh-ecdsa` keys, and values containing `.` or `:`; each needs a false-positive decision on prose and URLs.
* `lit_code_blocks` has the same fence shape gap as `lit_diagrams` (tilde fences, indented list fences not counted).
* The `hardware_bridge` Python list gained `smbus`/`smbus2`, `spidev`, `RPi`, `gpiozero`, `pigpio` (#4108 slice 5; the crucible holds none, golden unmoved). Still unnamed: `serial_asyncio`, `evdev`, `pyaudio`, `cv2` camera capture (each needs a contract call on what counts as a peripheral).
* Crucible additions (needs a release and pin bump, `docs/ecosystem.md`): mermaid/plantuml docs in more repos, a
  feature-flagged, RAG and LLM-app service, pyserial/BLE code under `data/python`.
* Safety bypass forms still unread: none known among the TLS-verification set of #6239 (Java trust-all, .NET and PowerShell accept-any callbacks and policies, `-SkipCertificateCheck`, `wget --no-check-certificate`, all read since #6414 / #6531 and this slice).
